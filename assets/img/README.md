# Görseller

Bu klasöre aşağıdaki adlarla dosya koyduğunuzda site onları otomatik kullanır.
Dosya yoksa site kendi renk geçişleri, ikonlar ve marka adlarıyla düzgün görünmeye devam eder.

| Dosya | Nerede görünür | Önerilen boyut |
|---|---|---|
| `hero.jpg` | Anasayfa arka planı | 2400×1400, yatay, deniz/tekne |
| `about.jpg` | Hakkımızda fotoğrafı | 1200×1500, dikey |
| `og-image.jpg` | WhatsApp/sosyal medyada link önizlemesi | 1200×630 |
| `services/mobil-enerji.jpg` | Mobil Enerji kartı | 1200×675 (16:9) |
| `services/solar.jpg` | Solar kartı | 1200×675 |
| `services/elektrik.jpg` | Elektrik Tesisatı kartı | 1200×675 |
| `services/su-yapici.jpg` | Su Yapıcı kartı | 1200×675 |
| `services/jenerator.jpg` | Jeneratör kartı | 1200×675 |
| `services/klima.jpg` | İklimlendirme kartı | 1200×675 |
| `services/hidrolik.jpg` | Hidrolik Sistemler kartı | 1200×675 |
| `brands/victron.png` … `brands/itamare.png` | Marka kutucukları | Şeffaf PNG, ~400 px genişlik |

Marka dosya adları: `victron`, `webasto`, `odyssey`, `spectra`, `sterling`, `balmar`,
`coelmo`, `engel`, `simarine`, `ibattery`, `sunpower`, `dessalator`, `itamare` (hepsi `.png`).

Kendi çektiğiniz montaj ve tekne fotoğrafları stok görsellerden çok daha fazla güven verir.
Fotoğrafları yüklemeden önce sıkıştırın (ör. squoosh.app), her biri 300 KB'ı geçmesin.
